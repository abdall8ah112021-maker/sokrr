# Sugar Business — Master Production System

منظومة **Sugar Business** المتكاملة لولاء العملاء، الكروت البلاستيكية الذكية، رموز الـ QR الموحدة، رصيد النقاط، شبكة التجار المعتمدين، المتجر الرسمي، والرقابة الإدارية الشاملة.

---

## 1. الهوية والعلامة التجارية
- **الاسم التجاري:** Sugar Business (لا يترجم)
- **الألوان الأساسية:** أسود / أسود داكن (`#07090e` / `#0c101c`) مع لمسات Baby Blue وسماوي مضيء (`#38bdf8` / `#0ea5e9` / `#7dd3fc`)
- **الاتجاه واللغة:** العربية الكاملة من اليمين لليسار (RTL) مع خط Cairo الطباعي الفاخر
- **العملة المعتمدة:** الجنيه المصري (EGP)
- **النطاق الزمني:** توقيت القاهرة (`Africa/Cairo`) مع حفظ الطوابع الزمنية في قاعدة البيانات بصيغة UTC

---

## 2. المكونات المعمارية (Full-Stack Architecture)
- **الواجهة الأمامية (Frontend):** React 19 + TypeScript + Vite + Tailwind CSS v4 + Motion
- **الخلفية والخادم (Backend):** Node.js + Express + TypeScript مع نقاط نهاية `/api/v1`
- **قاعدة البيانات (Database & ORM):** Prisma Schema + PostgreSQL (محرك ترانزاكشنز ودفتر أستاذ Ledger غير قابل للتلاعب)
- **الحماية والأمان (Security):** خوارزمية تشفير scrypt + Argon2id، رموز JWT مزدوجة (Access + Refresh Rotation)، قفل تصاعدي للحسابات بعد 5 محاولات فاشلة، وصلاحيات RBAC دقيقة على مستوى الخادم.

## 3. حسابات الاختبار التجريبية المعتمدة (Deterministic Demo Accounts #182)

| الدور | رقم الهاتف | كلمة المرور | الصلاحيات والمزايا |
|---|---|---|---|
| **المشرف العام (Super Admin)** | `01026541250` | `abdallah112021` | صلاحيات كاملة: تعديل النقاط اليدوي، إيقاف الكروت، تشغيل المهام، الإعدادات |
| **الشريك التجاري (Business)** | `01000000002` | `Password123!` | مسح الكروت، تأكيد الشراء، إضافة الموظفين، إنشاء العروض |
| **الكاشير الموظف (Employee)** | `01000000003` | `Password123!` | مسح كروت العملاء وتأكيد الشراء وإضافة النقاط فورياً |
| **العميل (Customer)** | `01000000004` | `Password123!` | كارت بلاستيكي ذكي (رقم `SUGAR-8849-2026`)، رصيد 350 نقطة، مستوى فضي |

> *ملاحظة:* يوجد زر "تجربة الأدوار" في شريط التنقل العلوي للتبديل الفوري بين جميع هذه الحسابات بنقرة واحدة لاختبار كافة مسارات وتجارب النظام.

## 4. مسارات ووظائف النظام الرئيسية

1. **الكارت البلاستيكي الذكي ورمز الـ QR:**
   - كارت 3D تفاعلي يدعم القلب بين الوجه والأظهر (Front / Back) مع انعكاسات ضوئية.
   - رمز QR حقيقي مولد تلقائياً برقم تسلسلي فريد يمكن مسحه لدى الكاشير.
   - التحقق الفوري من سلامة وحالة الكارت وصلاحيته قبل أي معاملة.

2. **دفتر الأستاذ وحركات النقاط (Point Ledger):**
   - حركات النقاط غير قابلة للحذف أو التعديل الرجعي (Earn, Spend, Expire, Adjust).
   - حماية ضد التكرار (Idempotency Key) لمنع ازدواج العمليات عند النقر المزدوج أو ضعف الشبكة.
   - صلاحية 6 أشهر لكل حركة نقاط مع تنبيهات استباقية.

3. **المتجر الرسمي والطلبات:**
   - فصل صارم بين منتجات الدفع عند الاستلام (COD) ومنتجات استبدال النقاط (يُمنع الخلط).
   - لقطات تاريخية ثابتة (Immutable Snapshots) للأسعار والمنتجات داخل الطلبات لحماية السجلات القديمة من أي تعديل مستقبلي.
   - حساب مصاريف الشحن تلقائياً حسب المحافظة.

4. **إدارة الشركاء ودليل المتاجر:**
   - 4 كروت في الصف على شاشات العرض الكبيرة (Desktop 4 cards per row).
   - اعتماد وإدراج المتاجر حصرياً بواسطة الإدارة.
   - خيارات الاتصال الفوري عبر الهاتف، واتساب، وتوجيهات الخرائط.

5. **المهام المجدولة وسجل التدقيق:**
   - تشغيل آلي أو يدوي لفحص انتهاء صلاحية النقاط، الكروت، والعروض.
   - تسجيل شامل لكافة العمليات الحساسة (Audit Log) متضمناً الفاعل، الحدث، التوقيت، والسبب.

## 5. التشغيل والتطوير (Getting Started)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير المتكامل (Express Backend + Vite Frontend على المنفذ 3000)
npm run dev

# فحص واختبار الأنواع
npm run lint

# بناء نسخة الإنتاج
npm run build

# تشغيل نسخة الإنتاج
npm run start
```
